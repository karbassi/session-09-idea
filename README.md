# Hair Salon Booking Website

A beautiful, professional booking website for your hair styling business, built with Next.js and ready to deploy on Vercel for FREE!

## What You Got

- Professional landing page with your business info
- Service listing with prices
- Booking request form
- Contact information and business hours
- Mobile-friendly responsive design
- Easy to customize without coding knowledge

## How to Customize Your Site

**All customization is done in ONE file: `config.js`**

Open the `config.js` file and edit:

1. **Business Name** - Change "Glamour Hair Salon" to your salon name
2. **Contact Info** - Update phone, email, and address
3. **Services & Prices** - Add, remove, or modify your services
4. **Business Hours** - Update your operating hours
5. **Colors** - Change the color scheme (use hex color codes)

No coding knowledge needed - just edit the text between the quotes!

## How to Deploy to Vercel (FREE Hosting)

### Step 1: Push to GitHub (DONE!)
Your code is already in your GitHub repository.

### Step 2: Create a Vercel Account
1. Go to https://vercel.com
2. Click "Sign Up"
3. Choose "Continue with GitHub"
4. Authorize Vercel to access your GitHub

### Step 3: Deploy Your Site
1. Once logged in, click "Add New Project"
2. Find your repository in the list and click "Import"
3. Vercel will auto-detect it's a Next.js project
4. Click "Deploy" (don't change any settings)
5. Wait 1-2 minutes for deployment to complete
6. You'll get a live URL like: `your-site.vercel.app`

### Step 4: Get a Custom Domain (Optional)
1. In your Vercel project, go to "Settings" > "Domains"
2. Add your custom domain (like www.yoursalon.com)
3. Follow the instructions to update your domain's DNS settings

## Making Changes After Deployment

1. Edit `config.js` with your changes
2. Save the file
3. Commit and push to GitHub
4. Vercel automatically redeploys your site (takes 1-2 minutes)

## Important Notes

**About the Booking Form:**
- Currently, form submissions show a success message but don't actually send anywhere
- To receive actual bookings, you'll need to connect a service like:
  - **Formspree** (easiest, free tier available)
  - **EmailJS** (sends to your email)
  - **Google Forms** (can integrate)
  - Or hire someone to add a backend

**This is a static site**, which means:
- No real-time calendar
- No automatic confirmation emails (yet)
- But it's 100% FREE to host on Vercel!
